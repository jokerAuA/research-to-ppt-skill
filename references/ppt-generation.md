# PPT 生成细则（阶段 D）

> 由 SKILL.md 阶段 D 引用。核心原则：**先让用户选模板，再尽可能多地调用
> 阶段 B/C 归档的真实资产**；禁止为省事而用占位图/空图框。

## 1. 模板选择（动手前必做）

用户提出"做 PPT"后、任何版式工作开始前，先询问模板偏好（一次问清，给
默认选项）：

- 选项 1：本 Skill 默认学术风格（如 burgundy_analyst 勃艮第学术答辩风，
  思源宋体 + 数据图图表库）；
- 选项 2：简洁商务（微软雅黑 + 白底深色）；
- 选项 3：用户自备模板（PPTX/在线 Slides，走 ppt skill 的模板流程）；
- 选项 4：复刻用户提供的样例页。

用户不明确时默认选项 1，并在交付说明里注明"默认模板"。选定后整个 deck
的配色/字体/留白全程遵守，不中途混搭。

## 2. 资产调用优先级（核心规则）

每一页先查阶段 C 的"逐页使用建议对照表"，按以下顺序找素材：

1. **已归档论文 figures/表格**（A 级优先）——最能体现"论文引用"价值；
2. **已归档网页原图/截图**（A/B 级，记录 URL）；
3. **真实数据 → 图表库数据图**（chart_slide，数字必须来自归档资料，禁编造）；
4. **生图兜底**（示意图/封面，仅前两类都缺失时）。

同一张图不跨页重复使用（Logo/统一装饰除外）。图片一律先下载到本地、
按需去底色、上传拿 file_token 后插入，禁止 http 外链；`<img>` 按原比例缩放，
附件提取图禁止裁剪。

## 3. 内容与来源纪律

- 每个关键数字必须能在归档索引里找到出处；找不到就回搜索补证据，
  仍无则明确标注"待补/示意"，不冒充事实。
- 引用论文图的页面，页脚写"图：<标题>（<论文名> p<页>）"；
  引用网页的页面，页脚写来源（短名 + 年份）。
- 演讲者备注 `<note>` 每页 3-5 句可照读讲稿，把图要表达的证据点说清楚。
- 用户后续说"能换的都换 / 图片太少"时：优先查对照表中未使用的 A 级资产，
  空间不足则新增"证据页"（一张页放 2-4 张相关论文图 + 图注），不硬塞挤爆版式。

## 4. 交付前检查清单

- [ ] 模板选择已确认（或已注明默认）；
- [ ] 对照表已逐页执行，A 级资产尽量用完；
- [ ] 所有图有来源标注（论文页/URL）；
- [ ] 数据无编造，索引可追溯；
- [ ] 逐页 lint 通过（或单页例外已截图核验）；
- [ ] 回读 21→N 页页序/页码核对、改动页截图目检；
- [ ] `drive +export` 导出 PPTX + present_files 双交付（在线链接 + 本地文件）。
