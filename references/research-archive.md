# 调研与资料归档细则（阶段 A / B）

> 本文件由 SKILL.md 的阶段 A、B 引用。目标：调研内容 → 搜索 → 把资料落地为
> **可直接论文引用**的本地资产（含来源备注），为阶段 C（论文资产提取）与
> 阶段 D（PPT 生成）提供素材库。

## 1. 调研起始（阶段 A）

1. 先完整理解用户主题，拆出核心概念、案例、数据、争议点四类信息需求。
2. 搜索优先级：
   - 通用搜索（general_search）：新闻、报告、政策、行业数据，一次并行 ≤3 个关键词；
   - 学术搜索：锁定论文时优先（如 scholar_search）；
   - 行业/垂直平台：用户点名来源（如微信公众号、知乎、B站）时走对应封闭平台流程；
   - 搜图：真实实体（人物/产品/地标/海报）才用 image_search；
   - 视频：实证视频/纪录片线索用 video_search。
3. 重要网页必须精读原文（web_fetch），摘要不足以支撑"可直接引用"。
4. 每个关键数字/事实必须记录来源（标题 + URL + 发布日期），不编造、不凭记忆。
   一手来源（官方文件、论文原文、ProPublica 类调查报道）优先于二手转述。

## 2. 资料归档目录结构（阶段 B）

在工作目录下建 `资料归档\`，固定分四类 + 一个总索引：

```text
资料归档/
├── 00-资料索引与备注.md        # 总索引（必建，见 §3）
├── 论文文献/                   # PDF 原文（命名含来源与主题，如《华盛顿大学CSE416-机器学习公平性讲义.pdf》）
├── 网页文章/                   # 精读后另存为 md（保留标题/URL/日期/要点/原引文）
├── 图片素材/                   # 搜图/下载的原始图片（记录来源 URL）
├── 视频链接/                   # 视频清单（标题/平台/链接/时长/要点，不用下载正片）
└── 论文图片素材/               # 阶段 C 产物（extract_pdf_assets.py 输出）
```

规则：
- 文件命名 = 来源标识 + 主题 + 类型，避免 "未命名1.png"。
- PDF 用原始文件名，md 网页文章头部固定三行：`来源: <URL>`、`发布时间: <日期>`、`要点: <3-5条>`。
- 所有资产都要可追溯：图/表必须能指到"来自哪篇论文第几页"或"来自哪个 URL"。

## 3. 总索引《00-资料索引与备注.md》格式

```markdown
# 资料索引与备注
> 主题：<主题> ｜ 归档日期：<日期> ｜ 用途：<最终交付物>

## 一、论文文献
| 文件 | 来源 | 页数 | 与本主题的关系 | 可提取资产 |
|---|---|---|---|---|
| ... | ... | ... | ... | 图x/表x |

## 二、网页文章
| 文件 | 来源 URL | 发布时间 | 关键数据点 | 引用价值(A/B/C) |

## 三、图片素材 / 四、视频链接 / 五、论文图片素材
（同表格式，视频含链接与时长）
```

## 4. 引用分级（所有资产统一用）

- **A 级**：直接支撑论点，可原样引用（论文原图、官方数据、一手报道截图）。
- **B 级**：有参考价值，但需裁剪/局部引用或非一手来源。
- **C 级**：仅背景/装饰，不作为论证证据。

PPT 页脚与演讲备注中必须写明 A/B 级资产的来源（论文名+页码 或 URL）。
